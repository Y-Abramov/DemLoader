# Загрузка рельефа

Модуль для Топоматик Robur: обводите участок на плане и получаете готовую цифровую модель
местности в дереве проекта - без ручного поиска, скачивания и сшивки данных рельефа.

## Что делает

- **Загрузить** (`dem_load`) - выбираете область (рамкой или замкнутой полилинией), источник и
  систему координат, модуль сам находит нужные тайлы, строит сетку
  точек и записывает готовую поверхность в проект.
- **Обновить** (`dem_update`) - перекачивает рельеф по уже сохранённому заданию (та же область,
  источник, шаг), заменяя содержимое существующей модели.
- **Удалить** (`dem_erase`) - убирает модель рельефа, созданную модулем, из проекта.
- **Выгрузить тайлы** (`dem_export`) - сохраняет исходные файлы GeoTIFF по области на диск, без
  построения поверхности - для стороннего ГИС-инструмента.
- **Настройки** (`dem_settings`) - личный ключ OpenTopography, лимит числа точек, папка кэша.

## Источники данных

- **Copernicus DEM** (ESA, GLO-30 и GLO-90) - основной источник, без регистрации и ключа.
  © DLR e.V. 2010-2014, © Airbus Defence and Space GmbH 2014-2018, лицензия COP-DEM.
- **OpenTopography** - по личному ключу пользователя (регистрация бесплатная). Условия сервиса
  запрещают вшивать ключ в приложение - модуль не может выдать его за вас.

Список источников можно дополнить своими - файл описан в диалоге настроек.

## Важно: характер данных

Данные - это цифровая модель **поверхности** (DSM), не рельефа земли: в отметки входят кроны
деревьев и крыши строений. Высоты отсчитываются от геоида **EGM2008**, а не от Балтийской
системы, принятой в проектах РФ - расхождение систематическое (дециметры, местами больше метра),
для его компенсации в диалоге загрузки есть поправка Z.

Модель годится для посадки объекта на местность и предварительной оценки объёмов. Она **не
заменяет инженерные изыскания** и не является основой проектных высотных отметок.

## Атрибуция

При выгрузке тайлов (`dem_export`) рядом с файлами сохраняется текстовый файл с указанием
источника, правообладателя и условий использования. Ссылка на источник обязательна при
публикации данных и в проектной документации - ответственность за соблюдение условий источника
несёт пользователь.
